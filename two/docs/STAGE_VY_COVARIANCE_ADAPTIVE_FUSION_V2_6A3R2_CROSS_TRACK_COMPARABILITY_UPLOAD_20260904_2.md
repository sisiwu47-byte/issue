# V2.6-A3R2 跨轨迹 covariance 可比性审计

## 结论

**COVARIANCE_SCALE_CALIBRATION_REQUIRED**

本阶段只读取既有五组非-holdout calibration MAT，未启动 MATLAB/Simulink/CarSim，未运行 `sim()`，未采集新数据，未修改 D/K/F、融合公式、Q/R 或参数入口。

## 数据与 F covariance 处理

使用 `FWCAL_C01R1`、`FWCAL_C02`、`FWCAL_C03`、`FWCAL_C04`、`FWCAL_C05`，统一采用冻结的 0–16 s、100 Hz、同时间戳 `Vy_true` 对齐、无去均值/去偏/滤波规则。

F 使用 A3R1 冻结 recurrence：

```text
P0_F = 0
Q_F  = 0.000525656083041383 (m/s)^2/step
P_F(n) = Q_F*n, n=0..1600
```

因此 t=0 的 n=0 样本保留为状态事实，但 `P_F=0` 时 `e²/P_F` 未定义。A1 implied-weight 诊断仅使用三路 covariance 均严格为正的 8000 个样本，并单独记录该 reset exclusion；没有选择 epsilon 数值，也没有把 epsilon 拟合成参数。

## A1 implied-weight diagnostic

仅在非 reset 的 8000 个正 covariance 样本上使用 A1 已冻结的 normalized inverse-covariance 等价公式；没有 epsilon 性能调参。

```text
mean alpha = [0.9954751136, 0.0017037519, 0.0028211345]
median      = [0.9974395925, 0.0014211562, 0.0008746923]
p05         = [0.9874785035, 0.0004917012, 0.0002795440]
p95         = [0.9991737120, 0.0037657126, 0.0098078821]
max-weight fraction = [1, 0, 0]
alpha > 0.90       = [0.9975, 0, 0]
alpha > 0.99       = [0.93725, 0, 0]
alpha < 0.01       = [0, 1, 0.95075]
```

这构成明确的 `SCALE_DOMINATED_WEIGHT_SATURATION`：D-track 几乎永久占据权重，不能解释为有意义的 time-varying confidence allocation。此判断不使用 `Vy_AF` RMSE，也不拟合任何 `c_i`。

## 时间变化关系与契约状态

协方差与 squared error 的 Pearson 相关范围为：D `-0.184..0.666`、K `0.494..0.893`、F `0.9746..0.9748`；F 的 Spearman 约 `0.999995`。这些仅为 descriptive diagnostics。

实际源码 `model/vy_feedback_propagation_step.m` 包含 `assert(P0_F > 0)`，因此：

```text
CURRENT_F_CORE_CONTRACT_ACCEPTS_ZERO = NO
```

这是后续独立 implementation blocker；本阶段不修改 core，也不修改 A3R1 冻结值。

## Verdict

```text
COVARIANCE_SCALE_CALIBRATION_REQUIRED
```

D/K/F 的量纲一致且均有可读 covariance，但 confidence scale 不兼容；A1 covariance-only weighting 不能直接作为无校准的正式 confidence allocation。后续若获授权，可在单独阶段研究 `P_eff_i = c_i P_i`，本阶段不求解 `c_i`。

冻结边界：不引入 LifeSig、NIS、observability、residual reliability、maneuver-specific hand tuning、holdout tuning 或 Q/R 调整；`P_AF` 仍为 `NOT_DEFINED`。
