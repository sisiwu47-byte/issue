# Repository Guidelines

# AGENTS.md

## 1. 项目目标

本项目在现有 MATLAB/Simulink 四轮独立驱动、四轮独立转向车辆模型旁，
实现一个纵向车速估计器。

当前阶段只实现：

1. 四轮轮速虚拟传感器；
2. IMU递推虚拟传感器；
3. 四轮有限时间窗速度增量一致性滑移识别；
4. 四轮连续可信度和自适应测量协方差；
5. 两个局部卡尔曼滤波器；
6. 局部滤波互协方差递推；
7. 考虑互协方差的最优融合；
8. 估计器复位、失效和降级模式逻辑。

当前阶段不使用GPS或北斗数据。

不得将任务扩展为控制器重构、车辆动力学模型重构、
轮胎参数辨识或侧向速度估计。

## 2. 项目目录

项目主要目录如下：

- `model/`
  - 现有控制器MATLAB函数；
  - 现有Simulink模型；
  - 只用于接口和参数核查。

- `specs/`
  - `implementation_spec.md`
  - `signal_interface.md`
  - 是本项目的直接实施依据。

- `references/`
  - 多虚拟传感器纵向车速融合论文；
  - WSS/IMU四轮滑移识别论文；
  - 只用于核对指定公式和理论来源。

- `matlab/`
  - 创建纵向车速估计器及辅助函数。

- `tests/`
  - 创建纯MATLAB单元测试、接口测试和回归测试。

- `results/`
  - 保存仿真结果、指标、图片和临时数据。

- `docs/`
  - 保存接口审查报告、人工连线说明和实现记录。

## 3. 指令优先级

发生冲突时，按以下顺序执行：

1. 用户当前任务指令；
2. `specs/implementation_spec.md`；
3. `specs/signal_interface.md`；
4. 当前 `AGENTS.md`；
5. `model/` 中现有Simulink和MATLAB接口；
6. `references/` 中的论文。

若规格文件与现有模型接口冲突：

- 立即报告冲突；
- 明确冲突文件、信号和位置；
- 不得自行选择其中一种解释；
- 不得未经允许修改模型来消除冲突。

论文公式与规格文件冲突时，以规格文件为准，因为部分论文方法已根据
CarSim输出信号的物理含义进行了适配。

## 5. 禁止修改的文件

未经用户明确许可，不得修改：

- `model/*.slx`
- `model/MPC_Demo3_wuguzhang.m`
- `specs/*.md`
- `references/*.pdf`
- CarSim数据集；
- 数据字典；
- 被引用模型；
- 控制器输入输出接口。

不得：

- 自动重连Simulink信号；
- 自动增加GPS通道；
- 改变控制器参数；
- 改变MPC输入和输出维数；
- 将CarSim真实纵向速度作为估计器输入；
- 用真实侧向速度代替阶段1的 `vy_prior=0`；
- 用简单逆方差融合替代指定的互协方差融合；
- 用其他滑移判断方法替换有限时间窗一致性判据。

如果模型需要人工增加或连接信号，只能生成：

`docs/simulink_manual_connection.md`

说明应由用户手工完成的连接，不得直接修改 `.slx`。

## 自动执行与中断规则

在本项目任务中，除非遇到真正无法继续的阻塞问题，否则不得向用户询问是否继续、是否覆盖、使用哪种方法或是否运行命令。

### 必须执行

- 收到阶段任务后直接开始读取、分析、写入和验证。
- 不要只给出计划，必须完成任务要求的目标文件。
- 文件已经存在但不完整时，允许直接覆盖该阶段文件。
- 命令失败时必须自行分析原因并尝试替代方法。
- 同一种方法最多重试2次，随后切换到替代方法。
- 中间结果不要等待用户确认。
- 使用规格文件中已经确定的参数和方法，不得再次向用户确认。
- 采用非关键假设时，将假设记录在结果文件中，不要停下来询问。
- 完成后必须检查目标文件存在、非空、结构完整。
- 只有完成最终验证后才向用户报告。

### 不得执行

- 不得修改specs、references、model目录中的文件。
- 不得修改.slx和控制器.m。
- 不得运行删除、格式化、覆盖工程原文件等破坏性命令。
- 不得联网搜索或安装依赖。
- 不得因为一个工具失败就终止整个任务。
- 不得把完整PDF、长代码或整个目录内容打印到终端。

### 允许停止的真正阻塞问题

仅在以下情况允许停止并报告：

1. 任务指定的必需文件不存在；
2. 文件损坏且所有允许的读取方法均失败；
3. 完成任务必须修改禁止修改的文件；
4. 当前环境缺少必需软件，且无法使用现有工具替代；
5. 执行会导致不可逆或破坏性修改。

上下文不足、首次命令无输出、文本编码错误或单一PDF工具失败，
均不属于允许停止的阻塞问题。
